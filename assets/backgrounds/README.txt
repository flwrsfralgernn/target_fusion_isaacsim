UAV Forge Isaac Sim Background Pack
====================================

Contents
--------
Eight square 2048 x 2048 PNG diffuse/color textures:

01_aerial_grass_rock.png
02_grass_path_3.png
03_gravel_ground_01.png
04_forest_ground_01.png
05_aerial_rocks_01.png
06_asphalt_023s.png
07_road_001.png
08_ground_030.png

Isaac Sim use
-------------
1. Create one Plane.
2. Create an OmniPBR or UsdPreviewSurface material.
3. Set the PNG as the diffuse/base-color texture.
4. Bind the material to the Plane.
5. Keep UV scale at 1 x 1 when using each PNG as one complete backdrop.
6. Use a square Plane, such as 50 m x 50 m, to avoid stretching.

These are visual backdrops only. Objects pictured by the texture do not have
3D geometry or collision. Avoid combining them with camera angles so low that
the flatness becomes obvious.
